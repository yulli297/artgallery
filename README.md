# 우리 반 가상 미술관

걸어다니며 명화 10점과 내 그림 1점을 거는 3D 전시관입니다.
6학년 1반~5반이 한 서버를 함께 쓰도록 미리 설정되어 있습니다.

## 파일 구성

```
virtual-gallery/
├─ server.js        서버 (로그인, 저장, 그림 올리기, 명화 목록)
├─ package.json     필요한 프로그램 목록
├─ .gitignore
└─ public/
   └─ index.html    화면 (3D 전시관)
```

GitHub에는 위 파일만 올리면 됩니다. `node_modules`, `data` 폴더는 올리지 않습니다.

## Render 배포

1. GitHub에 새 저장소를 만들고 위 파일들을 올립니다.
2. Render에서 **New → Web Service**를 누르고 그 저장소를 고릅니다.
3. 아래처럼 설정합니다.
   - Build Command: `npm install`
   - Start Command: `npm start`
4. **Environment** 탭에서 환경변수를 넣습니다(아래 표).

| 이름 | 값 | 꼭 필요? |
|---|---|---|
| `SESSION_SECRET` | 아무 긴 영문·숫자 (예: `gallery-2026-abcd1234xyz`) | 예 |
| `FIREBASE_CONFIG` | Firebase 웹 앱 설정(firebaseConfig) 전체 | 예 (실제 수업용) |
| `FIREBASE_SERVER_PASSWORD` | Firebase에 만든 서버 전용 계정의 비밀번호 | 예 (실제 수업용) |
| `TEACHER_PASSWORD_6_1` ~ `TEACHER_PASSWORD_6_5` | 반별 교사 비밀번호 (안 넣으면 `1234`) | 선택 |
| `CLASS_LIST` | 반 목록 (기본값 `6-1,6-2,6-3,6-4,6-5`) | 선택 |
| `MAX_STUDENTS` | 반별 최대 번호 (기본값 30) | 선택 |

- 교사 비밀번호는 모든 반이 `1234`로 설정되어 있습니다. 반별로 바꾸려면 위 환경변수를 넣으면 됩니다.
- `SESSION_SECRET`이 없으면 서버가 다시 켜질 때마다 모두 다시 로그인해야 합니다.

## Firebase 연결 (서비스 계정 키 없이)

학교·교육용 구글 계정은 조직 정책 때문에 **서비스 계정 키를 만들 수 없어요.**
그래서 이 서버는 키 대신 Firebase에 만든 **서버 전용 계정(이메일+비밀번호)**으로 접속합니다.
Firebase를 연결하지 않으면 서버 안 임시 폴더에 저장되고, Render 무료 서버는 다시 켜질 때 이 폴더를 지우므로 실제 수업 전에는 꼭 연결해 주세요.

### 1) 웹 앱 설정 복사 → `FIREBASE_CONFIG`
1. Firebase 콘솔 → 톱니바퀴 ⚙ → **프로젝트 설정** → **일반** 탭 → 아래쪽 **내 앱**으로 갑니다.
2. 앱이 없으면 **웹(</> 모양)** 아이콘을 눌러 앱을 하나 추가합니다(이름은 아무거나, 호스팅 체크 안 함).
3. **SDK 설정 및 구성**에서 **구성(Config)**을 고르면 `const firebaseConfig = { apiKey: ... };` 가 보입니다.
4. 이 부분을 통째로 복사해서 Render 환경변수 `FIREBASE_CONFIG`에 붙여넣습니다. (중괄호 `{ }` 부분만 붙여넣어도 됩니다.)

### 2) 서버 전용 계정 만들기 → `FIREBASE_SERVER_PASSWORD`
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기** → **이메일/비밀번호**를 **사용 설정**하고 저장합니다.
2. **Users** 탭 → **사용자 추가**를 누르고 아래처럼 만듭니다.
   - 이메일: `gallery-server@artgallery.app` (꼭 이대로)
   - 비밀번호: 직접 정한 긴 비밀번호
3. 이 비밀번호를 Render 환경변수 `FIREBASE_SERVER_PASSWORD`에 넣습니다.

### 3) Firestore 만들고 규칙 붙여넣기
1. **빌드 → Firestore Database → 데이터베이스 만들기** (위치: `asia-northeast3 (서울)`, 프로덕션 모드)
2. **규칙** 탭의 내용을 모두 지우고 아래를 붙여넣은 뒤 **게시**를 누릅니다.

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if request.auth != null && request.auth.token.email == 'gallery-server@artgallery.app';
    }
  }
}
```

### 4) Storage 시작하고 규칙 붙여넣기
1. **빌드 → Storage → 시작하기** (위치: 서울, 프로덕션 모드)
2. **규칙** 탭의 내용을 모두 지우고 아래를 붙여넣은 뒤 **게시**를 누릅니다.

```
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /{allPaths=**} {
      allow read, write: if request.auth != null && request.auth.token.email == 'gallery-server@artgallery.app';
    }
  }
}
```

규칙 덕분에 서버 전용 계정만 데이터를 읽고 쓸 수 있습니다. 학생 태블릿은 서버가 건네준 그림 주소로만 그림을 봅니다.

### 연결 확인
Render에서 다시 배포한 뒤 **Logs**에 아래 두 줄이 보이면 성공입니다.
```
[저장소] Firebase Firestore 사용: 프로젝트ID
[그림 저장소] Firebase Storage 사용: 프로젝트ID.firebasestorage.app
```
실패하면 로그에 이유가 한국어로 나옵니다. 예: 비밀번호가 틀림, 규칙이 막고 있음.
교사 관리 창에 노란 경고가 안 보이면 Firestore와 Storage가 모두 연결된 것입니다.

### 저장 구조 (서버 부담 줄이기)

| 위치 | 내용 |
|---|---|
| Firestore `classes` (반 1개당 문서 1개) | 전시 열림 여부, 학생 이름·비밀번호, 전시관 요약 |
| Firestore `galleries` (학생 1명당 문서 1개) | 구조, 벽·바닥 색, 명화 10점의 정보(제목·작가·연도·설명), 내 그림 정보 |
| Firestore `comments` (학생 1명당 문서 1개) | 내 그림 감상평 |
| Firestore `meta/catalog` | 추천 명화 목록 (30일마다 새로 만듦) |
| Storage `img/반/번호/` | 학생이 올린 명화와 내 그림 파일 |

- 그림 파일은 태블릿이 Storage에서 직접 받아서, Render 서버를 거치지 않습니다.
- 학교망에서 막히면 자동으로 서버를 거쳐 받습니다.
- 그림은 올리기 전에 자동으로 줄입니다. 명화는 긴 변 800px, 내 그림은 1024px입니다.
- 작품을 바꾸거나 내리면 쓰지 않는 그림 파일은 자동으로 지웁니다.
- 한 번 읽은 문서는 서버 메모리에 보관해서 Firestore에서 다시 읽지 않습니다.
- 친구 목록은 반 문서 1개만 읽고, 감상평은 그림을 눌렀을 때만 읽습니다.
- 저장은 바뀐 내용이 있을 때만 하고, 반 요약 문서는 4초에 한 번만 기록합니다.

## 사용법

### 선생님 (수업 전 준비)
1. 로그인 화면에서 **선생님** 탭 → 반 선택 → 비밀번호 `1234`로 들어갑니다.
2. **관리** 창에서 학생 수를 적고 **비밀번호 만들기**를 누릅니다. 번호마다 숫자 4자리 비밀번호가 무작위로 만들어집니다.
3. **비밀번호 인쇄**를 누르면 번호별 쪽지가 나옵니다. 점선을 따라 잘라서 나눠 주세요.
4. 학생이 비밀번호를 잃어버리면 **새 비밀번호**를 누르면 됩니다. 작품은 그대로 남습니다.

### 선생님 (수업 중)
- **전시 열기/닫기**: 열면 학생들이 친구 전시관을 구경하고 감상평을 남길 수 있습니다.
- **구경**: 학생 전시관을 바로 볼 수 있습니다.
- **이 작품 내리기**: 부적절한 그림을 누르면 나오는 버튼입니다.
- 감상평 옆 **지우기**로 감상평을 지울 수 있습니다.
- **이름**: 학생 이름을 고칠 수 있습니다.

### 학생
1. 반 → 번호 → 쪽지에 적힌 비밀번호를 넣고 입장합니다. 처음에는 이름을 적습니다.
2. 전시관 이름, 구조(긴 복도형, ㄱ자 2개 방, 팔각 홀, 가벽 전시실), 벽 색, 바닥을 고릅니다.
3. 빈 액자를 누르면 세 가지 방법으로 명화를 걸 수 있습니다.
   - **추천 명화**: 목록에서 고르기
   - **미술관 검색**: 영어로 검색하기
   - **내가 찾은 명화 올리기**: 인터넷에서 찾은 그림 파일 올리기
4. 제목·작가·연도·간단한 설명을 적으면 액자 옆 소개판에 나옵니다.
5. 금색 액자를 누르면 내 그림을 올릴 수 있습니다.
6. **저장**을 눌러야 친구들이 볼 수 있습니다.

조작 방법
- 키보드: WASD 또는 방향키로 이동하고, Shift를 누르면 빨리 걷습니다.
- 태블릿: 왼쪽 아래 원으로 이동합니다.
- 화면을 드래그하면 둘러볼 수 있습니다.

## 명화와 저작권

- 추천 명화와 미술관 검색은 시카고 미술관(Art Institute of Chicago)의 퍼블릭 도메인(CC0) 작품만 씁니다.
- 학생이 직접 올리는 명화는 **작가가 세상을 떠난 지 70년이 지난 작품**을 고르도록 안내해 주세요. 예: 김홍도, 신윤복, 고흐, 모네
- 우리 반 학생과 선생님만 로그인해서 보는 수업용 전시입니다.

## 다른 학교·학년에서 쓰기

이 저장소를 복사(fork)해서 각자 Render와 Firebase에 따로 배포하면 됩니다.
반 구성이 다르면 `CLASS_LIST`만 바꾸면 됩니다. 예: `5-1,5-2,5-3`
